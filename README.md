# Dubsvibe Music Streaming Web Application

A music streaming web application developed using Python and Flask. The application allows users to view songs, play music, and add new songs through a simple web interface.

## Features

- View available songs
- Play songs through the music player
- Add new songs
- Store song details in a database
- Simple and user-friendly web interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
